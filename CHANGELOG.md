## [1.1.0] — 2026-11-10

### Добавлено

- Поддержка самодельного последовательного программатора на Arduino/ESP:
  бинарный протокол с CRC16, прошивка `firmware/resetter-serial-i2c`,
  автопоиск порта и спецификация `serial:/dev/ttyUSB0`.
- Поддержка CH341A-совместимых плат с произвольным VID/PID
  (`ch341a:VID:PID`) и повторные попытки обмена с восстановлением шины.
- Автоматическая резервная копия перед записью и автоматическая верификация
  после записи.
- Профили картриджей с переопределением счётчика, защищённых и разрешённых зон.
- Проверка `allowed_modify_ranges` перед записью.
- HEX-редактор: переход к адресу, поиск байтов, заполнение `0x00`/`0xFF`,
  контекстное меню и горячие клавиши.
- Тесты протоколов CH341A и последовательного адаптера, тесты повреждённых
  контейнеров и расширенные тесты профилей.

### Исправлено

- Пакет чтения CH341A не содержал адрес устройства памяти.
- Адресация 24C1024: старший бит адреса теперь берётся из bit 16.
- Повреждённый контейнер `RSCHIPD1` больше не принимается за сырой дамп.
- Профили чипов `24Cxx` больше не содержат небезопасных универсальных
  смещений счётчика; исправлены защищённые зоны 24C16.
- Кнопки операций включаются только при наличии подключения, дампа и
  подходящего профиля.
- Профили картриджей теперь действительно загружаются и применяются.
- Безопасное завершение рабочего потока и удаление воркера.
- Согласованы имена файлов упаковки, каталогов установки и артефактов CI.
- Кроссплатформенная зависимость libusb: `pkgconfig(libusb-1.0)` вместо
  жёсткого `libusb1-devel`; добавлен отдельный RPM для RED OS 7.3.

## [1.0.0] — 2026-11-09

Первый публичный выпуск.

### Добавлено

- Графический интерфейс на Qt 6: панель подключения, картриджа, операций,
  HEX-редактор, журнал и статус-строка.
- Чтение дампов EEPROM `24C01 … 24C1024` через программатор CH341A (I2C).
- Обнуление счётчика страниц по смещению из профиля чипа или картриджа.
- Постраничная запись с пропуском неизменённых блоков и последующей верификацией.
- Валидатор защищённых диапазонов, блокирующий опасные изменения.
- Резервное копирование, восстановление и сравнение дампов.
- Контейнер дампа `RSCHIPD1` с метаданными, CRC32 и поддержкой «сырых» `.bin`.
- Сканирование шины I2C и выбор адреса устройства `0x50–0x57`.
- JSON-профили чипов и картриджей, переопределение каталога через
  `Resetter_CHIP_PROFILES`.
- Модульные тесты на Qt Test: контрольные суммы, дампы, профили, валидация,
  HEX-редактор.
- Упаковка RPM для Fedora и RED OS, udev-правило для доступа без `root`,
  Docker-образ для сборки.
- CI на GitHub Actions и автоматическая сборка RPM при публикации тега.

### Безопасность

- Отмена длительных операций и таймауты обмена с программатором.
- Санитайзинг аргументов и отказ от небезопасных конструкций при работе с файлами.
