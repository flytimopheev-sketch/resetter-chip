# Профили чипов и картриджей

Профили — JSON-файлы в `src/profiles/`. После установки они лежат в
`/usr/share/ressetter-chip/profiles`, каталог можно переопределить переменной
окружения `RESSETTER_CHIP_PROFILES`.

## Формат профиля чипа

Файл может содержать массив профилей или один объект.

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | string | Уникальный идентификатор, например `24C16` |
| `name` | string | Человекочитаемое имя |
| `size_bytes` | number | Размер EEPROM в байтах |
| `i2c_address` | number | 7-битный адрес устройства (80 = `0x50`) |
| `two_byte_address` | bool | Два байта адреса памяти (24C32 и крупнее) |
| `block_bits` | number | Биты адреса в байте устройства (24C04 → 1, 24C08 → 2, 24C16 → 3) |
| `page_size` | number | Размер страницы записи в байтах |
| `write_cycle_ms` | number | Пауза после записи страницы |
| `family` | string | Семейство, используется для фильтрации `24Cxx` |
| `counter_offset` | number | Смещение счётчика страниц; `4294967295` — не задано |
| `counter_size` | number | Размер счётчика: 1, 2 или 4 байта |
| `protected_ranges` | array | Диапазоны `{ "start": N, "end": M }`, `M` не включается |

> JSON не поддерживает `0x`-литералы — все значения записываются в десятичном
> виде. `0x50` → `80`, `0xFFFF` → `65535`.

Пример:

```json
{
  "id": "24C16",
  "name": "EEPROM 24C16 (16 Kbit / 2048 байт)",
  "size_bytes": 2048,
  "i2c_address": 80,
  "two_byte_address": false,
  "block_bits": 3,
  "page_size": 16,
  "write_cycle_ms": 5,
  "family": "24Cxx",
  "counter_offset": 255,
  "counter_size": 2,
  "protected_ranges": [
    { "start": 0, "end": 16 },
    { "start": 2032, "end": 2048 }
  ]
}
```

## Встроенные профили

`chip_24cxx.json` содержит геометрию всех поддерживаемых EEPROM:
24C01, 24C02, 24C04, 24C08, 24C16, 24C32, 24C64, 24C128, 24C256, 24C512, 24C1024.

`cartridge_example.json` — примеры профилей картриджей:

- `HP_CC364A` — HP CC364A / CE255A (LaserJet P2015, P2055), чип 24C16;
- `Samsung_MLT_D101S` — Samsung MLT-D101S (ML-2160, ML-2165), чип 24C08.

Профили картриджей содержат дополнительные информационные поля
(`printer_models`, `cartridge_models`, `page_resource`,
`allowed_modify_ranges`), которые используются интерфейсом и валидацией.

## Как добавить профиль

1. Определите тип EEPROM и его геометрию (datasheet: размер, страница, адресация).
2. Найдите смещение счётчика страниц в дампе (сравните дампы до/после печати).
3. Опишите защищённые диапазоны — серийные номера, контрольные суммы,
   области, которые нельзя менять.
4. Добавьте запись в JSON и проверьте загрузку профиля:

   ```bash
   RESSETTER_CHIP_PROFILES=./src/profiles ./build/ressetter-chip
   ```

5. Прогоните тесты: `ctest --test-dir build --output-on-failure`.

## Проверки при загрузке

- профиль без `id` или с `size_bytes == 0` пропускается;
- ошибка разбора JSON пишется в лог, остальные файлы продолжают загружаться;
- защищённые диапазоны не должны выходить за пределы `size_bytes`;
- при записи `Validator` блокирует изменения в защищённых диапазонах.
