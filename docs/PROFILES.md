# Профили чипов и картриджей

Профили — JSON-файлы в `src/profiles/`. После установки они лежат в
`/usr/share/resetter-chip/profiles`, каталог можно переопределить переменной
окружения `RESETTER_CHIP_PROFILES` (старое имя `Resetter_CHIP_PROFILES`
поддерживается).

## Формат профиля чипа

Файл может содержать массив профилей или один объект.

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | string | Уникальный идентификатор, например `24C16` |
| `name` | string | Человекочитаемое имя |
| `size_bytes` | number | Размер EEPROM в байтах |
| `i2c_address` | number | 7-битный адрес устройства (80 = `0x50`) |
| `two_byte_address` | bool | Два байта адреса памяти (24C32 и крупнее) |
| `block_bits` | number | Биты адреса в байте устройства |
| `page_size` | number | Размер страницы записи в байтах |
| `write_cycle_ms` | number | Пауза после записи страницы |
| `family` | string | Семейство, используется для фильтрации `24Cxx` |
| `counter_offset` | number | Смещение счётчика страниц; `4294967295` — не задано |
| `counter_size` | number | Размер счётчика: 1, 2 или 4 байта |
| `protected_ranges` | array | Диапазоны `{ "start": N, "end": M }`, `M` не включается |
| `allowed_modify_ranges` | array | Необязательный белый список изменяемых зон |

`block_bits`:

| Чип | Значение | Откуда берутся старшие биты адреса |
|-----|----------|-------------------------------------|
| 24C01, 24C02 | 0 | — |
| 24C04 | 1 | биты 8…8 адреса памяти |
| 24C08 | 2 | биты 8…9 |
| 24C16 | 3 | биты 8…10 |
| 24C32 … 24C512 | 0 | двухбайтовый адрес памяти |
| 24C1024 | 1 | бит 16 адреса памяти |

> JSON не поддерживает `0x`-литералы — все значения записываются в десятичном
> виде. `0x50` → `80`, `0xFFFF` → `65535`, `0xFFFFFFFF` → `4294967295`.

## Профиль чипа

```json
{
  "id": "24C16",
  "name": "EEPROM 24C16 (16 Kbit / 2048 байт)",
  "size_bytes": 2048,
  "i2c_address": 80,
  "two_byte_address": false,
  "block_bits": 3,
  "page_size": 16,
  "write_cycle_ms": 5,
  "family": "24Cxx",
  "counter_offset": 4294967295,
  "counter_size": 2,
  "protected_ranges": [
    { "start": 0, "end": 16 },
    { "start": 2032, "end": 2048 }
  ]
}
```

Для универсальных чипов `counter_offset` обычно не задаётся: расположение
счётчика зависит от картриджа. Обнуление счётчика становится доступно после
выбора профиля картриджа.

## Профиль картриджа

Профиль картриджа ссылается на профиль чипа и уточняет его:

```json
{
  "id": "HP_CC364A",
  "name": "HP CC364A / CE255A (LaserJet P2015, P2055)",
  "chip_profile": "24C16",
  "printer_models": ["HP LaserJet P2015", "HP LaserJet P2055"],
  "cartridge_models": ["HP CC364A", "HP CE255A"],
  "counter_offset": 255,
  "counter_size": 2,
  "counter_initial_value": 0,
  "page_resource": 3500,
  "protected_ranges": [
    { "start": 0, "end": 16, "description": "Идентификатор производителя и модель" },
    { "start": 2032, "end": 2048, "description": "Контрольные суммы и регион" }
  ],
  "allowed_modify_ranges": [
    { "start": 16, "end": 2032, "description": "Счётчик страниц и пользовательские данные" }
  ]
}
```

При выборе картриджа приложение:

1. берёт геометрию из `chip_profile`;
2. подставляет `counter_offset` и `counter_size` картриджа;
3. заменяет защищённые зоны, если они заданы;
4. применяет `allowed_modify_ranges`, если список задан.

`counter_initial_value` и `page_resource` — информационные поля для интерфейса
и будущих отчётов.

## Встроенные профили

`chip_24cxx.json` содержит геометрию всех поддерживаемых EEPROM:
24C01, 24C02, 24C04, 24C08, 24C16, 24C32, 24C64, 24C128, 24C256, 24C512,
24C1024.

`cartridge_example.json` — примеры профилей картриджей:

- `HP_CC364A` — HP CC364A / CE255A (LaserJet P2015, P2055), чип 24C16;
- `Samsung_MLT_D101S` — Samsung MLT-D101S (ML-2160, ML-2165), чип 24C08.

## Как добавить профиль

1. Определите тип EEPROM и его геометрию (datasheet: размер, страница,
   адресация, напряжение).
2. Найдите смещение счётчика страниц в дампе (сравните дампы до/после печати).
3. Опишите защищённые диапазоны — серийные номера, контрольные суммы,
   области, которые нельзя менять.
4. Добавьте запись в JSON и проверьте загрузку профиля:

   ```bash
   RESETTER_CHIP_PROFILES=./src/profiles ./build/Resetter-chip
   ```

5. Прогоните тесты: `ctest --test-dir build --output-on-failure`.

## Проверки при загрузке

- профиль без `id` или с `size_bytes == 0` пропускается;
- размер страницы должен быть степенью двойки;
- `counter_offset + counter_size` не должен выходить за `size_bytes`;
- защищённые и разрешённые диапазоны не должны выходить за `size_bytes`;
- при записи `Validator` блокирует изменения в защищённых зонах и вне
  `allowed_modify_ranges`.
